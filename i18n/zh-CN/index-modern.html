    隐私政策

    本 HTML5 测速服务器已开启遥测（结果记录）。

    我们收集哪些数据

    测速结束后，会收集并保存以下数据：

    • 测试 ID
    • 测试时间
    • 测试结果（下载/上传速度、延迟、抖动）
    • IP 地址
    • 运营商信息
    • 大致位置（根据 IP 推断，非 GPS）
    • 浏览器 UA 与语言
    • 测试日志（不含个人信息）

    数据用途

    通过本服务收集的数据用于：

    • 生成可分享的测试结果（论坛图片等）
    • 改进服务质量（例如发现服务端问题）

    不会向第三方披露任何个人信息。

    你的同意

    开始测速即表示你同意本隐私政策的条款。

    数据删除

    如需删除你的信息，请提供测试 ID 或 IP 地址。这是识别你数据的唯一方式，缺少这些信息我们将无法处理请求。
